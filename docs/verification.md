## Игровой прогон (бот, реальный сервер 1.21.1, регион tw_mine)

Профессия `mine`: зарплата 3.0 за действие, 2 XP, цена `COBBLESTONE` = 1.0,
буст денег x1.5 (куплен за 5000).

```
4 блока (без авто-скупки):   действия 4, XP 8,  заработок $12      = 4 x 3.0
/autosell on, 3 блока:       действия 7, XP 14, заработок $24      = 12 + 3x(3.0+1.0)
/tw stats:                   "mine: ур. 1, XP 14, действий 7, заработано $24"
скупщик (3 cobblestone):     баланс $24 -> $27, инвентарь очищен от cobblestone
покупка "Кирка глубин":      $125 027 -> $75 027 (цена 25 000), предмет в инвентаре
буст денег x1.5:             $75 027 -> $70 027 (цена 5000)
%tradewind_boost_money%:     1.50
%tradewind_profession%:      Шахтёр
%tradewind_level%:           1
%tradewind_progress%:        14
/tw top mine:                1. TestMiner — 7 действий, $27, ур. 1
```

С бустом, 2 блока, авто-скупка включена: 9 действий и $39 = 27 + 2x(3.0x1.5 + 1.0x1.5).
XP при этом +4 (2 за блок, буст опыта не покупался) — множители не перепутаны.

## Замечания, найденные проверкой и исправленные

* `PALE_OAK_LOG` отсутствует в 1.21.1 → убран из `prices.yml`.
* Перезапись конфигов ради новых ключей удаляла комментарии → новые ключи берутся из jar без
  изменения файла; пересоздание осталось только при смене версии схемы (с резервной копией).
* Авто-скупка по умолчанию переустанавливалась при каждом входе → применяется только к новым профилям.
* Подписи в `/prof` печатались пустыми на существующем `messages.yml` → добавлены ключи и слияние.
